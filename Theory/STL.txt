Pairs : 

(part of utility library)
Syntax: <int,int> p {1,3}
Access : p.first , p.second , etc

To store more than 2, for example 3 or 4 variables,
we can use the nested property of Pairs
Syntax: pair<int , pair<int,int>> p = {1,{2,3}};
Access : p.first , p.second.first, p.second.second,etc

we can also declare a pair array : 
Syntax : pair<int,int> arr[] = {{1,2},{2,4},{3,4}};
Access : arr[1].second;

Vector : 

Vector is a container which is dynamic in nature which stores elements.
Syntax : vector<int> v; //creates an empty container

vector functions  : 
1. v.push_back(3); //enters the 3 inside our vector container
2. v.emplace_back(2); //dynamically increases the size of the container and puts 2 in it after 3.

vector<int> v(5,100) //this declares a container of size 5 with 5 instances of 100
vector<int> v(5) //this declares a container of size 5 with 5 garbage values

these stored values look somewhat like : 
{100,100,100,100,100} and {0,0,0,0,0}
______________________________________________________________
Iterator :
(basically points to the memory where the element lies)
Syntax : vector<int::iterator it = v.begin();
other iterators are v.end(), v.rend(), v.rbegin()

Set : 
everything is sorted.
everything is unique.
Syntax : set<int>st;
_________________________________________________________________________
multiset : 
everything is sorted.
everything is stored.
Syntax : multiset<int>st;
__________________________________________________________________________
unordered set : 
everything is same as set but dosen't store in sorted order.
Syntax : unordered set<int>st;
__________________________________________________________________________
Map : (unique keys are stored , but the values can be the same)
Syntax : map<int,int>st;
